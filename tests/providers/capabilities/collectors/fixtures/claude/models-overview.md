# Models overview

## Compare models

If you're unsure which model to use, start with [Claude Opus 5](/models/opus-5/overview); for the highest available capability, use [Claude Fable 5](/models/fable-5/overview).

| Feature | Claude Fable 5 | Claude Opus 5 | Claude Sonnet 5 | Claude Haiku 4.5 |
| :--- | :--- | :--- | :--- | :--- |
| Description | Next-generation intelligence | For complex agentic coding | Speed and intelligence | The fastest model |
| Comparative latency | Slower | Moderate | Fast | Fastest |
| Claude API ID | `claude-fable-5` | `claude-opus-5` | `claude-sonnet-5` | `claude-haiku-4-5-20251001` |
| [Thinking](/build-with-claude/thinking) | Adaptive (always on) | Adaptive | Adaptive | Extended |
| [Context window](/build-with-claude/context-windows) | <Tooltip tooltipContent="fixture">1M tokens</Tooltip> | 1M tokens | 1M tokens | 200K tokens |
| Max output | 128K tokens | 128K tokens | 128K tokens | 64K tokens |
| Claude API alias | `claude-fable-5` | `claude-opus-5` | `claude-sonnet-5` | `claude-haiku-4-5` |

Legacy models (still available): [Claude Opus 4.8](/models/opus-4-8/overview), [Claude Opus 4.6](/models/opus-4-6/overview), [Claude Sonnet 4.6](/models/sonnet-4-6/overview).

# Performance And Security

## Measure First

- Profile representative workloads under the production runtime and host. PUC
  Lua, LuaJIT, OpenResty, Luau, and patched VMs optimize different shapes.
- Measure allocation volume, table growth, string construction, GC time,
  coroutine switches, module loading, and Lua/native crossings.
- Keep a correctness test and benchmark/profile artifact for each material
  optimization.

## Common Hot Paths

- Build large strings from parts with `table.concat` when repeated `..`
  construction is measured as costly.
- Reuse stable tables or buffers only with clear ownership and reset semantics.
  Pooling mutable tables can trade allocation for aliasing bugs and retained data.
- Reduce Lua/C crossings by batching only when latency, error localization, and
  API clarity remain acceptable.
- Localize globals or reshape tables only when profiles justify it. Keep readable
  code for cold paths.
- Tune incremental/generational GC settings against production allocation and
  latency data. GC behavior and optimal parameters vary by release and platform.

## Loaded Code And Search Paths

- Treat source text, bytecode, rockspecs, native modules, FFI declarations, and
  loader search paths as executable input.
- For restricted source loading, choose the intended text/binary mode and an
  explicit environment where the target Lua version supports them.
- Do not accept untrusted precompiled chunks as a portable or safe interchange
  format. Keep generated bytecode tied to its exact runtime and trust boundary.
- Prevent writable or attacker-controlled directories from entering trusted
  `package.path` or `package.cpath` resolution.

## Capabilities And Limits

- Expose only required libraries and host callbacks. Review filesystem, process,
  network, environment, dynamic loading, debug, registry, and FFI access.
- Validate input depth, element counts, string sizes, numeric ranges, and output
  size before recursive traversal or host conversion.
- Enforce memory and execution budgets from the host. Instruction hooks can aid
  cooperative limits; stronger adversaries need process or OS isolation.
- Avoid secrets in globals, registry values exposed to scripts, tracebacks, logs,
  serialized tables, or reusable pooled state.
- Reset or discard state between tenants according to the host's isolation
  contract; `package.loaded`, globals, metatables, and closures retain state.

# New visual work

Treat `.impeccable.md` as the visual authority. When it needs creation or
revision, return to Impeccable teach mode before continuing.

Call `get_skill_file(name="impeccable", path="references/new-work-direction.md")` to decide what is true, ask only consequential questions, choose the amount of invention, and commit the visual world.

After direction is fixed, call `get_skill_file(name="impeccable", path="references/new-work-build.md")`. Before delivery, call `get_skill_file(name="impeccable", path="references/new-work-finish.md")`. Keep these three references as the complete activation budget; reuse existing domain references only when the selected direction explicitly requires one.

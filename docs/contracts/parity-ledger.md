`delegated`, or `dropped by decision #N` (a positive task number). Notes cite evidence
or blocking Rust work; string entries have empty notes. Pipes and line breaks in notes
are escaped for the table. Malformed entries are errors.

decision. `proxied` and **unclassified** rows still block retirement. This makes

Edit your group file in `docs/contracts/parity-ledger-status.d/`, then regenerate.
All JSON shards merge in filename order; duplicate surface keys are errors.
Each entry is a status string or an object: `{"status": "proxied", "note": "Rust work"}`.
Objects require exactly `status` and `note`, both strings. Statuses are `proxied`,
`delegated`, or `dropped by decision #N` (a positive task number). Notes cite evidence
or blocking Rust work; string entries have empty notes. Pipes and line breaks in notes
are escaped for the table. Malformed entries are errors.

Exit rule: every row must be `delegated` or `dropped by decision <ref>` with a recorded
decision. `proxied` and **unclassified** rows still block retirement. This makes
#21574 Retire gobby-backend a mechanical deletion; its exit check is owned there.
The native terminal default flip has its own evidence row referencing #21357
Plan native runtime completion. A closed planning task alone does not prove the flip.
